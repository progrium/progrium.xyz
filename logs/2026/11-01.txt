vx32: Lightweight User-level Sandboxing on the x86
2026-11-01 · link · https://pdos.csail.mit.edu/papers/vx32:usenix08.pdf

Bryan Ford and Russ Cox's paper on sandboxing untrusted x86 code entirely in user space, with no kernel changes or special privileges. Vx32 confines guest memory access with segmentation and runs guest code through a dynamic translator that rewrites unsafe instructions, so most code runs close to native speed. Its applications include portable archive decoders and 9vx, which runs the Plan 9 kernel as an ordinary process on another OS.
