🛠️ tailcat: Tailscale without Tailscale, by Tailscale ↗ github.com

tailcat is netcat over Tailscale's data plane without its control plane. One side listens and gets a short address, the other connects to it, and traffic flows over end-to-end WireGuard tunnels that bootstrap through DERP and then hole-punch to direct UDP when they can. Connection metadata is exchanged out of band however you like, so there's no Tailscale account, no root, and no changes to routing or DNS. It ships as both a CLI and a Go library.

🛠️ isobox: Run a command in a sandbox, with the same flags on every OS ↗ github.com

isobox is a Go CLI that compiles one sandbox policy to each OS's native mechanism: Seatbelt on macOS, gVisor on Linux, and AppContainer on Windows. Instead of pretending every backend is equal, it uses an explicit capability model that flags where enforcement falls short, and a strict mode that refuses anything that isn't portable.

📄 vx32: Lightweight User-level Sandboxing on the x86 ↗ pdos.csail.mit.edu

Bryan Ford and Russ Cox's paper on sandboxing untrusted x86 code entirely in user space, with no kernel changes or special privileges. Vx32 confines guest memory access with segmentation and runs guest code through a dynamic translator that rewrites unsafe instructions, so most code runs close to native speed. Its applications include portable archive decoders and 9vx, which runs the Plan 9 kernel as an ordinary process on another OS.
